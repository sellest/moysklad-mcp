# Доработка аналитики MCP МойСклад — 10.10.2026

Локальная версия 3.2.0, 64 инструмента. Основание — `Проверка_фиксов_MCP_размеры_сентябрь_2026.md` и сохранённые JSON из соседнего каталога `work`. Ранее исправленные endpoint прибыльности, query-периоды, архивность и пагинация позиций сохранены. Изменения не опубликованы в npm и не развёрнуты на VPS.

## Реализовано и проверено

- [x] Компактный JSON; один текстовый `content`, без дублирующего `structuredContent`. Обычный документ содержит шапку и `positions_export.items`, без `positions.rows`. Полный API-объект — явный `raw`.
- [x] Контракт номенклатуры: assortment ID/type, отдельный родитель, выбранные характеристики, size/size_raw, null вместо догадок. Старый product_id сохранён как ID номенклатуры, включая модификацию.
- [x] Размеры: период, организации, категории, диапазон/шаг, исключения и override с доказательством. Двенадцать итоговых строк, отдельные продажи/возвраты/net, исключения/неопределённые строки и баланс учёта.
- [x] Ценовые диапазоны по фактическим позициям: десятичные границы, явные включения, запрет пересечений, outside/unresolved, контроль учёта. Цена не заменяется средней ценой товара.
- [x] Decimal.js: точность 80 значащих цифр, сравнение до округления. Тест 12500.006 сохраняет две единицы outside при верхней границе 12500. Возвраты используют собственную цену/скидку документа, другое основание не принимается.
- [x] Inline/file: ресурс `moysklad-export://…`, ресурсная ссылка и чтение через `resources/read` либо постраничный инструмент. Проверено по реальному локальному HTTP MCP на последующих запросах. Файл не дублируется в ответе и не выдаётся за локальный путь клиента.
- [x] Наборы полей в документах, поиске каталога и обычных отчётах; quantity исключает деньги. Повторяющиеся карточки расшифровки агрегатов вынесены в dictionary. Позиции ссылаются через assortment_ref.
- [x] Пагинационные total/returned/next_offset/complete в перечисленных списках и агрегатах. Неизвестный total не доказывает полноту; файловый режим документов/каталога сохраняет запрошенную страницу с её метаданными, а не обещает все страницы.
- [x] Опубликованные tools/list проверены после двух независимых инициализаций и на новом HTTP-запросе: новые инструменты, expand, positions_limit/offset, detail/output. Даты с временем и без покрыты тестами.
- [x] Компактная сверка количества с прибыльностью, ограниченные примеры; дополнительная сверка денег включается явно. Каталог кешируется в памяти отдельно для учётных данных, имеет версию и checked_at; проверены TTL, refresh, изменения версии и изоляция учётных данных.
- [x] Снимок сентября воспроизведён производственными агрегаторами, а замер новых ответов использует производственный рендерер и MCP-обёртку. Только агрегаты и численные метрики сохранены в verification, без клиентских карточек или токена.

## Объём ответов модели

Подробные цифры: [analytics-measurements.json](analytics-measurements.json). Токенизатор `js-tiktoken`, кодировка **o200k_base**. Измеряется весь сериализованный **MCP result** с content/text, включая экранирование JSON; у новых ответов включены period, source, catalog, rules и policy_hash. Транспортный JSON-RPC-конверт, запросы модели, системный prompt, framing и схемы инструментов в эти числа не входят. Точная кодировка выбранной пользователем модели неизвестна.

| Сценарий                                  |    Токены | Символы JS | Байты UTF-8 |
| ----------------------------------------- | --------: | ---------: | ----------: |
| До: реконструкция выгрузки для двух задач | 3 758 338 | 11 339 366 |  11 900 053 |
| После: краткий отчёт размеров             |       992 |      3 117 |       3 123 |
| После: краткий отчёт цен                  |      1005 |      3 836 |       3 836 |
| После: сумма ответов двух задач           |      1997 |      6 953 |       6 959 |

**Ограничение сравнения «до»:** нет полного лога прежних MCP-ответов. Реконструкция использует те же сохранённые строки документов, полный снимок карточек вариантов/товаров и отчёт продаж, заворачивая их в текстовые MCP-результаты. Карточки снимка в исходной проверке также извлекались напрямую через API, поэтому это стоимость передачи доступной подробной выгрузки модели, а не подтверждённый расход прежнего MCP-клиента. Недоступные raw-шапки не придуманы; ранее возможное дублирование raw-позиций тоже не добавлено. Числа не следует выдавать за точный процент экономии реальной прошлой сессии. Доказанный размер новых итоговых ответов — 1997 токенов суммарно. Если клиент загрузит весь экспорт, его объём снова попадёт в контекст; экономия относится к запросу итогов, с выборочным чтением расшифровки.

## Файлы и эксплуатация

Основные изменения: src/report-lib.ts, src/tools/documents.ts, src/tools/catalog.ts, src/tools/products.ts, src/tools/reports.ts, src/tools/reports_extra.ts, src/lib.ts, src/index.ts. Новые модули: src/precision.ts, src/output.ts, src/analytics-data.ts, src/classification.ts, src/tools/analytics.ts, src/tools/reconciliation.ts. Новые проверки: tests/analytics.test.ts, tests/compact.test.ts; дополнены tests/http.test.ts. Зависимости: decimal.js и dev-токенизатор js-tiktoken. README содержит режимы, примеры, смысл идентификаторов и правила расчёта.

Перезапустите локальный сервер через start-local.ps1; `/health` должен вернуть версию 3.2.0 и 64 инструмента. Эта работа не перезапускает чужой существующий процесс и не меняет токен. Файлы экспорта доступны час и до перезапуска, максимум 100 активных файлов/100 MB на файл; очистка просроченных файлов выполняется при следующем создании. Они хранятся во временном каталоге сервера, не являются публичными браузерными ссылками. Ресурсное чтение доказано на уровне протокола MCP; удобство отображения ссылки конкретным ChatGPT пока не проверено, поэтому есть запасной постраничный инструмент.

Источники не транзакционны: проверка стабильности total не обнаружит любую одновременную замену строк при неизменном количестве. При изменениях бизнеса во время расчёта повторите сверку. Кеш карточек имеет TTL 5 минут; для принудительной актуализации используйте refresh_catalog. Размер/категория из сегодняшнего каталога, не из его исторического состояния. Входные числовые значения API проходят JSON number до Decimal.js; уже потерянные значащие цифры восстановить невозможно.
